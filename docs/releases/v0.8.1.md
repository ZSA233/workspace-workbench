# 0.8.1

空间统计按 Workspace 活跃程度更新，减少重复遍历；后台统计期间仍可查看已有结果和清理缓存。

- 每个 Workspace 独立安排统计：24 小时内活跃为 10 分钟，1～7 天为 1 小时，7～30 天为 1 天，更早为 7 天。当前使用的 Workspace 优先；全局缓存为 30 分钟，项目共享缓存为 10～60 分钟。
- 打开缓存页复用已有结果，只更新到期项；关闭页面后完成当前目录并暂停剩余任务。逐项保存进度，暂停、清理打断或重启后复用已完成项。
- 扫描不再整体禁用清理按钮。清理请求优先，跨项目统计在安全检查点让出执行，清理后只使受影响的路径失效，旧结果不能覆盖新状态。
- 普通刷新更新到期项，新增“全量重新统计”；重复请求合并，正在执行的普通刷新可升级为全量统计。
- 最近提交、真实使用及已知代码／准备活动用于判断活跃程度。快照读取、手动 Git 刷新和统计发布不会使冷 Workspace 持续变热。
- 部分更新继续处理共享目录、重叠路径及硬链接去重，混合统计时间的合计标为估算；失败保留上次成功值并延迟重试。

验证：TypeScript 检查及 791 项 Node 测试通过。真实隔离 Paseo Web 宿主验证连续打开复用快照、扫描期间查看与清理、重复刷新合并、原生 Go 编译缓存清理、项目切换，以及浅色／深色／390px 面板。真实清理仅使用临时缓存。

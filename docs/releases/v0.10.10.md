# 0.10.10

包含 0.10.9 的话题原件状态刷新和 Paseo 会话自动 MCP 身份修复。0.10.9 标签的发布验证因新增连接测试缺少临时宿主端点而失败，未产出正式发布包；本版补齐隔离测试环境，不依赖本机已有 Paseo 状态。

话题图片按相同附件 ID 核对归档状态，展开的前台内容每 10 秒刷新尚未就绪的附件，就绪后停止；刷新不启动采集任务，也不改变已选材料。关联项目的普通 Paseo 会话默认自动获得独立 MCP 身份，已有会话可在下一轮自动恢复，保留会话、历史和模式，无需手填桥接配置或 Token。连接检查分别报告服务连通和身份是否随请求传入；缺少身份不会派发写入，也不再建议反复检查连接重试。

验证：本机 TypeScript 和 902 项 Node 测试通过，最终 MCP 调整的 26 项相关测试通过。真实隔离 Paseo 宿主及本地 Codex 协议夹具验证连续两次插件更新后的老会话恢复、两个新项目自动接入、实际 HTTP MCP 备注读写及越权拒绝；未使用用户项目写入测试备注。浏览器验证图片由待就绪自动更新为可见、就绪后停止轮询、手动刷新及原材料选择保持，深色和 390px 面板无页面脚本错误。

| 方案 | 文件 | 视觉特点 |

每个文件都是独立 SVG。Paseo 的官方标志路径保持原样，调整尺寸和位置后放在袋面后方；
不透明的口袋前片遮住标志下方的一部分。各方案的图层和配色仍可调整。
对照图包括上轮原始 A，方形和圆形小图只展示缩小及裁切效果，并非 Android 实机截图。

原始标志来源和许可证见[上一轮草图说明](../README.md#标志来源与署名)。

# 变化文件筛选交互草稿

生成日期：2026-11-16。以下为基于现有插件截图生成的布局方案，图中数据用于布局示意。最终已选择 B 并完成实现；这些生成图不作为实际运行截图。

使用内置 image_gen 工具生成，并对文字、筛选状态与数量一致性做了一轮定向校对。提示词记录见 [prompts.md](./prompts.md)。

共同约束：

- 沿用现有字体、浅色背景、分隔线、紧凑行、提交图和整体布局。
- 树形／列表合并为一个切换按钮，用省出的位置放“…”。
- 保留说明筛选入口；不增加独立测试按钮；桌面图标按钮保留约 28px。
- 同一套操作适用于未提交变化、单个提交和分支比较。
- 测试文件可全部显示、弱化或隐藏；弱化文件名与标题，保留变化状态和增删颜色。
- 搜索支持包含、排除与文字／路径模式，使用临时浮层。
- 项目规则可覆盖内置语言／框架预设，无法确定的文件正常显示。

| 方案 | 操作方式 | 空间与取舍 |
| --- | --- | --- |
| [A · 菜单优先](./a-menu-first.png) | 测试显示方式在菜单中直接选择，搜索另开浮层 | 平时最紧凑，复杂筛选多一步 |
| [B · 集中浮动筛选](./b-floating-filters.png) | “…”展开集中面板，同时调整包含／排除、测试显示与说明状态 | 不增加常驻行，展开时暂时覆盖文件列表 |
| [C · 条件可见](./c-visible-conditions.png) | 菜单与浮层设置，生效后显示可清除的条件摘要 | 条件直观，启用筛选时多占一行 |

实现采用 B。使用方式、匹配规则和记忆范围见 [插件说明](../../../paseo-plugin/README.md#compare-连续阅读)。

生成图已人工查看。以上仅为视觉设计证据；实现后的实际宿主界面另行通过隔离 Paseo 与 Playwright 验证。

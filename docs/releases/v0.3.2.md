# Workspace Workbench v0.3.2

This patch restores Android native surface rendering by removing the React error-boundary wrapper from the native entry components. The Paseo Android renderer treated that boundary as an undefined element before the Workbench implementation was entered.

- Native surface, workspace-panel, and file-panel entries now render the checked component directly.
- The native-loading regression test prevents the incompatible boundary from returning to the Android entry path.

Validation: TypeScript typecheck, the full 223-test suite, and the native-loading regression test passed locally.

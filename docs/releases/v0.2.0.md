# Workspace Workbench v0.2.0

This release makes repository observation event-driven, bounds MCP request lifecycles, and adds main-workspace controls.

- The main workspace can discover and select Git repositories independently of managed Workspace creation. Repository names such as `go-secrets`, `node_modules`, and hidden directories are no longer silently excluded. Project-configured `discovery.exclude` remains effective; newly discovered repositories remain unchecked.
- Main-workspace Agent Review is manual, independent, and read-only. It uses the project's review instructions and selected repositories without requiring an execution Agent.
- A concise Workspace submission can pass a task and original paths, return a durable request ID immediately, and continue asynchronously. The existing preview/execute interfaces remain available.
- Git observation uses filesystem events with bounded reconciliation. A missing repository is reported on its own row, while short backend delays retain the last snapshot instead of repeatedly showing a global failure.

Validation: TypeScript typecheck and 180 Node tests passed. An isolated Paseo host and headless browser verified the repository picker, live file updates, plugin reload, backend recovery, and zero additional Git commands during 16 idle seconds.

Existing Agent MCP processes keep their loaded version until the host reconnects them. Reloading the plugin updates the backend and new MCP processes without interrupting all active sessions.

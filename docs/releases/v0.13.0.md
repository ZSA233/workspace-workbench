# 0.13.0

将“摘要”重做为“会话”：只显示当前 PASEO 会话关联的 Workspace，自动更新短摘要，点击整行即选择该工作区并进入 Git。顶部工作区选择与会话上下文分离，跨项目各自记忆；平铺列表沿用现有 Git/话题主题和密度。

撤下统一设置首页与“设置”Tab，恢复扩展、存储、运行时、审核和恢复的原入口及弹窗。原 `⋯` 菜单新增单一“模型设置”弹窗，直接配置地址、模型、可选认证及项目命名偏好，高级项默认收起。

标题维护改为逐会话确认授权。预览不写标题，“应用并开启”才启用；外部改名暂停，关闭保留当前题。旧项目开关不再自动纳入，旧连接、schema-v1、未知字段和历史继续保留。关联变化、材料/消息变化、停用、配置修改和未知写入结果均有写入保护。

模型每批最多四个变化工作区；会话标题独立综合全部工作区和增量讨论，默认侧重最近 Git 改动。目标、说明、自身提交和必要差异分配输入预算，发布及生成内容降低优先级。短来源编号保留可逆映射并校验对象归属；缓存建议可直接核对，长历史不会因打开预览重复归纳。

类型检查、986项 Node 回归和实际隔离宿主的八项交互检查通过；覆盖深浅主题及320/360/480/680px。真实 Sushi/YUVA 试验生成“公会统计慢查询优化”，实际业务标题未写入。隔离 UI 使用协议/模型夹具并可回放真实模型文案，与真实模型证据分别记录。

# Workspace Workbench 0.7.0

文件树现在可以直接打开只读文件查看页，文件查看与 Git Diff 共用语言识别、语法高亮和主题配色。

- 桌面双击文件、按 Enter 或从菜单打开；触控设备单击打开，长按保留操作菜单。桌面使用主区域，Pocket 使用可返回的全屏查看页。
- Markdown 默认显示排版，可切换源码。支持表格、引用、代码块，以及通过现有认证连接读取的相对文件链接和图片；文档内的 HTML 和脚本不执行。
- 通用高亮覆盖 Go、JS/TS/JSX/TSX、Python、Java、Kotlin、Swift、C/C++/C#、Rust、Shell、SQL 和常见配置、标记、样式文件。未知类型保留纯文本。
- 后端按完整版本解析跨行语法，Diff 的左右版本分别处理。新增、删除和行内差异背景保留，展开上下文不再切碎源码重新解析。
- 查看页支持行号、搜索、自动换行、字号调整、复制和下载。大文件分段读取并虚拟化显示；搜索与复制明确限定于已加载内容。UTF-8 和 UTF-16 BOM 文件按原编码读取。
- 解析 Worker、请求队列和缓存均有边界。超出高亮预算时仍可阅读源码；切换主题只更新配色，空间切换和迟到响应不会覆盖当前文件。
- 打开预览不创建传输任务。下载继续先选择保存位置，确认后才开始传输，并重新检查文件版本。

本版本保持 Paseo 0.12 兼容，不需要新增 Pocket 原生桥；Pocket 沿用 0.1.6。

发布前已通过类型检查、Node 完整回归、隔离实际 Paseo 宿主中的文件查看与 Diff 浏览器验证，以及 Hermes 兼容性检查。Windows 实际客户端和 Pocket 物理设备仍待验收；浏览器移动视口与 Hermes 检查不代替真机结果。

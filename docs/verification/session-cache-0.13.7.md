# 会话缓存、共享 Git 读取与当前投递目标

2026-11-27，针对真实 YUVA“关系，退款”会话测量。修改前，连续两次普通进入耗时分别为 5.231 秒和 5.101 秒，均零次模型请求，时间主要花在五个仓库的完整材料读取；五分钟模型间隔判断发生在这些读取之后。摘要缓存没有避免前置的 Git 工作。

## 共享路径

- Git 页、分支比较和上线检查使用同一个 `RepositoryRefresh.sourceGit` 基础读取合并器及原始状态缓存，上线覆盖放入已有 `ObservationCache`。取消一个消费者不取消另一个消费者正在使用的生产者；生产者有独立超时并随后端退出回收。
- 会话使用同一变更监听的来源版本，包含后端身份、工作区实例、实际路径、任务元数据、提交／文件／引用变更、改动说明版本、交接内容及生产分支配置。版本可靠且未变化时复用已保存材料；监听准备中、事件尚未合并、监听失败或旧后端不支持版本接口时，沿用完整读取。
- 材料复用最长受生产刷新间隔约束，默认十五分钟；既有监听租约、闲置回收与核对机制保留。生产引用获取继续使用现有有界且有请求记录的 Git 路径。实际标题写入仍校验当前材料与外部改名，同标题不重复进入写入流程。
- 普通进入和预览均可复用会话消息头，未变的部分历史不重新处理。轻量检查保持已有结果可见，有实际读取或生成时展示进度。

## 验证

TypeScript 与 1,015 项完整 Node 测试通过。真实临时 Git 测试验证了 Git 页状态可供上线检查使用、并发整理只产生一次覆盖计算、连续热读取不启动 Git、实际文件／生产引用变更使缓存失效、取消单一消费者不影响共享结果。会话服务测试验证开启维护后的进入、预览、重新加载、单个 Workspace 变化、到期及降级回退。模型测试为 HTTP 替身，不计作真实本地模型证据。

20 项实际隔离 PASEO 界面检查通过。开启会话维护后连续三次检查均在两秒内完成，零模型请求、全部材料缓存命中，没有重新读取材料或执行同标题写入核对。原有菜单、关联、跨项目工作区选择与四种宽度的深浅主题回归通过，浏览器页面异常为零。上线依据在独立弹窗列出分支、数量和原因，主列表用“上线待核实”区别于整理任务。

话题投递验证预先保存另一会话和“新建会话”偏好，再在实际宿主打开当前会话，确认默认显示当前会话；手动更换目标在该次弹窗中生效，关闭后重新打开恢复当前会话；切换到另一原生会话后默认目标随之更新。测试未发送归档材料。服务端冻结预览、回执及材料选择范围继续保留。

隔离界面使用临时 Git、协议 Agent、HTTP 模型与归档服务夹具；正常安装后的真实 YUVA 耗时和启用记录单独保存，不将夹具结果冒充正式部署证据。

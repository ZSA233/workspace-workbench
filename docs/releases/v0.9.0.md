“需求与反馈”改为“话题”：从 AI 助手服务读取关注群的话题，选择原文、上下文和图片，在底部材料区核对后带入开发会话。

- 精简界面说明，用选中底色、勾选、状态点、媒体缩略图和数量呈现材料范围。
- 原文与附件独立选择、移除；已有分析默认不带入。刷新不扩大已选范围，预览固定原文版本与原件。
- 简单设置提供连接、资料库、关注群、自动建题及既有工具授权。采集、DWS 和模型配置由 AI 助手服务管理。
- 提示使用固定状态栏；保留输入焦点和材料区位置。未知投递只查询原回执，不自动重发。
- 暂时隐藏“审核集”和“Agent 审核”页签。

原件交接沿用宿主支持的图片、PDF、文本格式和单件 8 MiB 上限。旧扩展 ID、API-v1 SDK、历史候选和需求记录保持兼容。

验证包含类型检查、相关 Node 回归、独立 Go 服务兼容性、真实 AI 助手接口只读核对，以及隔离 Paseo 宿主的宽/窄屏交互检查。会话发送成功路径使用 Agent 协议样例验证。

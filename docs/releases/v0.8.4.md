# 0.8.4

Workspace 选择器打开即使用现有提交快照。后台优先核对发生变化的仓库、当前选用和可见的 Workspace，其余仓库按近期活动分批核对。

- 单个 Workspace 涉及的仓库核对完成后更新该项。界面在滚动停稳后应用排序，保留可见行和当前选择。
- 普通刷新检查到期和已知变化的仓库。「… → 全量检查提交」可核对项目全部有效仓库，显示进度并支持取消。
- 复用已保存的提交时间。HEAD 保持相同时跳过 Git 读取，共用 Git 对象的 Worktree 可合并读取提交时间。
- 插件包同时包含已提交的项目沟通扩展，默认停用。启用后可连接独立的 Communication Service，并按项目设置来源和模型覆盖。

在隔离 Paseo 宿主中使用 106 个托管 Workspace、主工作区及 430 条 Git 仓库路径验收。已有快照时首行可操作的 p95 为 14 毫秒。连续开关十次，HEAD 核对从 2,255 次降到 0，滚动停稳后首个可见行位移为 0 像素。TypeScript 检查和 823 项 Node 测试通过。

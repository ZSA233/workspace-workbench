# Workspace Workbench v0.4.3

This patch makes the shared MCP gateway recover at a stable address and reports whether the Paseo plugin route is ready before Agents use it.

- Preserve each Paseo home’s gateway port and key across plugin reloads and gateway crashes; wait for a verified prior owner and report unverified port conflicts without changing the address.
- Check Paseo and plugin RPC readiness before injecting the gateway, expose `workbench_connection_status`, and restart a crashed gateway with bounded backoff.
- Count HTTP queue time toward request deadlines, keep Workspace writes on the full budget, and return stable request identities for uncertain create and submit results.
- Ensure the project backend is ready before dispatching writes, so a cold backend after reload is reported as not dispatched.
- Update the isolated live verification to exercise actual MCP HTTP create calls across plugin reloads with the same URL and headers.

Validation: TypeScript typecheck, the full 241-test Node suite, and isolated actual-Paseo verification passed. The live check created a Workspace through MCP before and after plugin reload without changing the gateway URL or key.

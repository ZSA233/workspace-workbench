# Paseo Pocket 0.1.8

修复会话输入框选完图片后可能一直没有缩略图的兼容问题，versionCode 为 9。

- 对图片选择入口补齐缺失或错误的文件类型；实际识别到图片后继续走原有草稿与发送流程。正常图片保留原始内容、名称和时间。
- 读取失败时结束本次选择并允许重选；处理期间显示状态，较慢时提示等待缩略图。选择图片不会自动发送。
- 草稿暂存失败提供可见反馈与有限诊断，不再只有无响应的表象。设备存储故障仍需重试或处理原因。
- 适配器属于 APK 自有代码，只作用于可信的内置 Paseo 0.12 图片入口，保留经过校验的上游网页资产和文件保存桥。

脚本、网页资产、JVM、lint 与 QA／正式构建通过。真实 Android 设备的触发原因和兼容性仍待验收；[验证记录](https://github.com/ZSA233/workspace-workbench/blob/android-v0.1.8/android-app/VERIFICATION-0.1.8.md)区分浏览器、模块回归和设备证据。

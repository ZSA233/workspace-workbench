# 0.13.9

在原有「⋯ → 模型设置」补齐标题样式入口：简洁符号、彩色 emoji、短文字及五种状态的自定义符号，实时展示各状态的标题效果。命名提示词和标题长度移到主表单，与命名偏好一起配置；模型预算和超时继续折叠在高级设置中。

样式按项目保存，取消编辑不改配置。只改变符号且正文版本已核对时，预览复用原正文，不重复调用模型；保存后的预览需要确认后才能继续维护，旧预览不能越过新配置确认。正文规则或模型改变仍重新生成。旧记录保留，并在原配置核对后补充可选正文版本字段。

生产状态继续由 Git 证据决定。模型提示词只指导正文，原生列表使用标题字符及 emoji；插件不修改宿主列表的字体颜色。生产分支仍通过 Git 比较设置配置，判断原因可在会话页「上线依据」查看。

# 0.13.13

补齐生产覆盖与 Git 状态自动维护。

- 对补丁上下文已变化的文件，增加有界、按行位置核对的当前内容证据：需求实际修改行必须在生产中保留原有对应位置，邻近内容可以独立增删改。支持普通合入、squash 和 cherry-pick，不以提交 SHA 相同作为要求。重复片段、需求行被改写或移除、删除边界重叠、旧值恢复、无效文本和证据截断不能通过这项证明。
- 已开启自动维护的会话订阅既有 Git 观察版本，每 5 秒合并读取轻量版本标记；标记不变不读取完整材料或调用模型。变化后按既有 debounce（默认 30 秒）合并处理。插件重载后恢复既有授权范围的订阅，不开启其他会话。
- 上线符号与未提交笔号可以独立于模型等待时间更新，沿用已接受的标题正文。旧摘要或预览仍保持其真实过期状态；外部改名、暂停、关闭、配置改变和结果不明的写入保护保持生效。
- 整理版本查询进入既有桥接只读恢复及控制请求路径，不被短期响应缓存遮住；所有 Git 读取继续使用共享缓存、有界队列和输出限制。

不改变模型连接、提示词、关联、Workspace ID、目录或生产分支，不提交或清理用户工作区文件。

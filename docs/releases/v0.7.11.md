# Workspace Workbench 0.7.11

修复 Access Pocket 中「文件 → 下载 / ZIP」因 WebView 暴露浏览器保存接口而绕过 HTTP 下载交接的问题。Access 由原生保存器流式写入；普通桌面浏览器及独立 Paseo Pocket 仍沿用原有保存方式。

新增回归覆盖：WebView 同时存在 `showSaveFilePicker` 时，实际下载仍创建远端任务、核对目标主机并进入同源 HTTP 交接，不调用浏览器写入器、不在网页暂存正文。兼容旧 Pocket 写入桥及桌面浏览器，受影响文件测试与类型检查通过。设备端验收由 service-access-ops 记录。

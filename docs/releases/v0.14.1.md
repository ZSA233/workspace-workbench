# 0.14.1

修复文件树中 `.git`、`.workspace-workbench` 等内部目录无法展开的问题。现在可以进入目录、分页浏览和预览文件，目录及子项标明「只读」。Git worktree 的 `.git` 指针文件可阅读，但不会跟随其中的路径。

上传、新建、粘贴、改名、剪切和删除继续由后端保护，界面禁用相应入口。内部元数据的复制与 ZIP 规则保持不变，传输临时项继续隐藏。更换主文件根目录或选择目录别名不会绕过写保护；独立选中的开发 Workspace 保持正常写入。

验证：版本一致性、TypeScript、1,100 项完整 Node 回归和发布包检查通过。在隔离 Paseo home、项目注册表和真实临时 Git 仓库中加载实际插件，19 项宿主检查及 30 项 Chromium 交互检查通过，页面与控制台错误为 0。浏览器检查覆盖目录展开、只读文件预览、写入入口禁用、返回普通目录后恢复上传，以及原有文件传输流程。

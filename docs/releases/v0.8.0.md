# 0.8.0

新增「缓存与空间」Tab，并优化 Workspace 选择器的布局和最近提交排序。

- 选择器默认列表视图，可切换来源层级视图并保存选择；层级累计缩进最多 24px。主工作区参与最近提交倒序，相同时间使用稳定 ID 排序，未知时间置后。
- 打开时保留提交快照，后台核对 HEAD，修复 30 分钟内新增提交不更新、打开时切回其他排序和旧扫描覆盖的问题。整轮完成后统一更新，保持当前选择和可见行位置。
- 缓存页提供统计摘要、全局 Go 缓存、项目共享／Workspace 独占缓存及 Workspace 目录占用。统计独立后台执行，快照有效期为 10 分钟，手动刷新可跳过有效期；共享目录、重叠路径和硬链接去重，不递归跟随符号链接。
- Go 编译缓存与模块缓存独立预览、手动清理，分别通过固定目标目录执行 `go clean -cache` 和 `go clean -modcache`。不提供按天或自动清理，也不追加文件删除回退。持久化请求身份用于查询不确定响应，重启后不自动重放清理。
- 缓存层采用工具提供者接口，首期只注册 Go；后续工具可复用任务、统计、快照和页面。现有缓存路径和 schema-v1 Workspace 记录保持兼容。
- 工作区入口以宿主目录为准，完整读取分页目录；缺少上下文时提示选择项目，避免沿用其他工作区的项目。来源已删除时不额外插入空层级行。

验证：TypeScript 检查、776 项 Node 测试通过；真实隔离 Paseo Web 宿主验证列表／层级、视图记忆、30 分钟内新提交、快速开关、滚动锚点、项目切换、原生 Go 编译缓存清理，以及浅色／深色／390px 面板。真实 Go 清理验证仅使用临时缓存。

# 0.12.3

让摘要与设置在插件内形成完整操作流程。设置首页直接展示模型地址、自动整理开关、扩展管理、项目存储和审核等入口；Diff 字号、换行与并排显示保留在原工具栏。

摘要区分项目、会话和 Workspace。选择材料、模型生成、核对预览与应用标题分步呈现；支持取消、重试、人工事项维护、批量历史预览、独立应用确认、排除与恢复。默认只展示当前任务，输入、来源、生产证据和运行历史按需展开。

整理任务记录用途、作用范围、当前对象、阶段、实际模型请求及结果。生产核验不会调用模型；空范围不回退至整个项目；恢复任务保留原意图。轻量状态查询只读取本地记录，变化时才刷新摘要，不触发 Git 或模型。分类切换不再新增整理任务。模型运行保存实际模型与地址，保留失败记录，校验失败不作为有效预览。

修正无改动仓库影响已上线汇总的问题；同一会话里新出现的讨论 Workspace 仍单独参与汇总。保持 schema-v1、历史及未知字段、原生对象身份、人工改名保护，以及现有执行、审核、恢复和话题服务的行为。

验证：TypeScript、971 项 Node 回归、实际隔离 PASEO 的设置与摘要交互检查，包含 320/360/480/680px 分配宽度、真实原生标题字符、模型夹具请求、取消/重试、人工勾选、确认应用与恢复。真实业务模型试点只生成历史预览，不批量改名。

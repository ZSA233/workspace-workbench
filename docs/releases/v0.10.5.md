# 0.10.5

话题视频显示缩略图与时长，Web UI 可播放原视频并查看时间点画面。兼容档案接口仍把已保存视频标为 `pending` / `video` 的情况，以及旧话题快照缺少附件的情况；仅核对同一版本原文和受控原件接口，保留原始归档。完整的媒体传输占位串不再作为正文展示。

发送会话同时交付视频原件与最多 4 张时间点画面，画面使用宿主原生图片输入；接收会话保留可播放的视频卡片，刷新后仍可查看。音频不自动转写，画面抽取依赖主机 FFmpeg / ffprobe，处理失败不会降级成只有文件描述的发送。

发送确认直接选择保留原名或姓名缩写，并记住上次选择。中文名采用拼音首字母，非中文名保留原样；同缩写使用稳定标记区分，补选上下文保持既有对应。发言者、已确认的 @ 提及及回复关系同步处理，不再按选材顺序生成 A/B/C。

验证：TypeScript 与全量 Node 检查 889 项，888 通过、1 项可选 Go 检查跳过。Mac mini（Paseo 0.17.1）与 Mac Studio（Paseo 0.16.1）分别通过隔离真实宿主的 25 项界面验收，覆盖视频播放、刷新后视频卡片、姓名缩写与选择记忆。模型交付使用本地协议夹具核对 MP4 原件及 JPEG 图片字节，没有向真实模型发送测试任务。

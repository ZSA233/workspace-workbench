# 0.10.7

此版本仅保留源码标签，未生成正式发布包；正式发布见 [0.10.8](v0.10.8.md)。

修复工作区选择列表在冷仓库出现新提交后仍等待低频轮询，导致排序更新不及时的问题。打开选择器后立即保留已有列表，并在后台轻量核对项目内超过 30 秒未检查的 Git HEAD，包括屏幕外的工作区；短时间重复打开复用已完成的检查，后台恢复及快速关闭重开也能触发补查。

提交检查队列完成一项后会让出事件循环并填充空闲位置，去掉积压任务每批固定等待下一次轮询的延迟。保留当前选用和可见项优先、最多 4 个 HEAD 探测和 2 个 Git 读取，以及日常分级频率。未变化的 HEAD 复用提交时间，不遍历工作区目录，不触发空间统计；逐项更新排序并保留选中工作区。

验证：TypeScript 与 894 项 Node 测试通过。真实临时 Git 仓库中，250 个工作区、500 个仓库大部分未变时，后台整轮核对由约 15.8 秒降至 0.18 秒；500 个仓库全部有新提交时约 1.18 秒。真实隔离 Paseo 宿主模拟一个屏幕外冷工作区漏掉引用监听，重新打开列表后约 3.8 秒显示新排序，选中项不变；1280px 页面和 390px 面板通过，无页面错误，刷新期间未检测到浏览器长任务。上述时间为本机测试结果，实际时间随仓库数量和磁盘性能变化。

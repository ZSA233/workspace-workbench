# 0.8.2

按方案 B 集中管理变化文件筛选，默认弱化测试文件，减少未提交变化、单提交和分支比较中的阅读干扰。

- 树形／列表合并为一个切换按钮，保留说明入口和文件计数；新增「…」浮层，集中提供包含／排除、文字／路径模式、测试文件三态及说明状态。筛选即时生效，显示匹配数和隐藏数。
- 测试文件支持全部显示、弱化和隐藏。弱化保留代码与增删颜色；隐藏同时作用于文件列表、连续 Diff 和文件导航，已经单独打开的文件标签继续可读。
- 首批识别预设覆盖 Go、Python、JS／TS、Java／Kotlin 的明确源码路径约定，不按 `test` 子串判断。项目可停用预设、追加测试规则，或指定优先按普通文件显示的路径；非法规则保留上次有效结果。
- 显示偏好及识别规则按本机项目保存，同项目各 Workspace 和比较入口共用。包含／排除及说明筛选按当前上下文保留会话状态，不串用到其他项目或比较。
- 筛选保留目录展开和可见内容的滚动位置；当前阅读文件被隐藏时，按原顺序移动到下一个或前一个可见文件。筛选只使用已有改动路径，不增加目录扫描，不改变 Git 比较身份及审核范围。
- 浮层适配窄面板、浅色／深色和触屏，支持关闭按钮、点击外部和 Escape。设置 schema 升级至 4，保留既有选择、布局与其他设置。

验证：TypeScript 检查及 815 项 Node 测试通过。真实隔离 Paseo Web 宿主完成文件筛选、分支比较与连续 Diff 三组验收，覆盖项目隔离、设置恢复、滚动锚点、保留文件标签、浅色／深色、280～1000px 面板及触屏模拟，未发现页面脚本错误。Android／iOS 真机尚未验证。

# Paseo Pocket 图标草图：沿用官方标志

状态：已选择 A2 并用于 Android 图标。这里保留讨论时的草图，原对照图中的状态文字反映绘制时的情况。

[查看对照图](overview.png) · [可编辑的 SVG 对照图](overview.svg)

根据反馈继续探索了[用口袋前片遮住标志的五种方案](a-pocket-study/README.md)。

| 方案 | 文件 | 设计 | 小尺寸取舍 |
| --- | --- | --- | --- |
| A 口袋承托 | [a-pocket-cradle.svg](a-pocket-cradle.svg) | 在完整的官方标志外加入口袋轮廓。 | 标志清楚；口袋线条较细。 |
| B 随身角标 | [b-pocket-badge.svg](b-pocket-badge.svg) | 保留官方标志，在右下角加入口袋徽标。 | 更接近官方应用图标；角标较小。 |
| C Pocket 铭牌 | [c-pocket-wordmark.svg](c-pocket-wordmark.svg) | 在官方标志下方加入 POCKET 铭牌。 | 大尺寸名称明确；桌面小图标里的文字难以辨认。 |
| D 随身设备 | [d-mobile-frame.svg](d-mobile-frame.svg) | 浅色背景与手机外框包围官方标志。 | 手机外框较清楚；官方图形相对较小。 |

四个方案均为独立、可编辑的 SVG，使用相同的官方路径，仅调整整体尺寸、位置或颜色。
对照图中的小图标是缩小示意，不能替代各安卓桌面、图标蒙版及系统主题下的实机验证。
若选择 C，在正式转换 Android 资源时还需将文字转为路径，避免设备字体差异。

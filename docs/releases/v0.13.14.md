# 0.13.14

会话“自动更新标题”改为直接开启并在后台处理，不再把开启操作绑定到预览确认。

- 开关立即保存当前会话的授权；已有有效建议复用缓存，正在进行的整理复用原任务，等待队列或模型不阻塞开关。离开会话页后继续处理。
- 关闭立即撤销授权并取消当前更新；快速开关按最后选择生效，旧结果不能把已关闭的维护重新打开。
- “预览标题”保留为可选流程，仍可手动预览和应用。修改命名规则后可以直接重新开启，首次处理不必等待之前的分析间隔。
- 初次维护的待处理授权持久保存并在重载后恢复，后台失败显示原有错误，不对相同资料固定重试。队列满时保存开启意图，稍后再进入有界队列。
- 写入仍核对开启时看到的原标题、关联、当前资料与配置版本。外部改名仍暂停维护；结果未知的标题写入仍必须显式核对，不由开关自动重放。

保留现有模型连接、秘密、历史和 schema-v1 数据；升级不改变原有会话的开启状态。

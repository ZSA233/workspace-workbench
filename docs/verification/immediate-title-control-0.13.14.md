# 会话标题维护开关即时生效

2026-11-28，修正开启标题维护必须等待预览、再确认的交互。旧客户端把 On 调用接到预览弹窗，RPC 的 `enabled` 甚至限定为 `false`。现在 On 只保存当前会话的授权并安排后台处理；Off 撤销授权并取消任务。预览保留为可选操作。

## 环境与验证范围

使用实际隔离 PASEO home、项目注册表、真实临时 Git、协议 Agent 与 HTTP 模型夹具；没有重载正常插件来运行测试，也没有派发档案材料。Browser plugin not available，沿用仓库现有 Playwright 工作流。页面标题为 Paseo，同源侧栏路由身份核对通过。宿主视口 1440×1000，面板与设置在 320／360／480／680px、深浅主题检查。HTTP 模型夹具仅用于制造确定的排队和延迟，不作为真实本地模型质量证据。

## 已验证变化

- 有效建议在后台复用缓存；已有普通整理任务不重启、不重复请求模型。首次开启保存待处理授权，核对当前标题、材料与配置后再通过原有日志路径写入。
- 另一个会话占用项目队列时开启，开关先变为 On 并持久保存，队列任务仍未开始，无预览弹窗；最终测试的开关反馈约 19 毫秒。离开会话页后继续生成并更新实际原生标题。
- 模型请求期间 Off 立即生效，任务取消，原生标题与修改历史不增加。主动取消只显示“已取消”，不会同时呈现失败提示。
- Node 回归覆盖快速 On-Off-On、待处理授权重载恢复、缓存与标题不变时的接管、新命名配置、失败可见但不固定重试、外部改名暂停、未知写入禁止自动重放。开关请求与刷新查询分离，后一个 Off 不等模型或查询刷新完成。

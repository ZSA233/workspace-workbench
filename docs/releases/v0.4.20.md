# v0.4.20

- Edit or withdraw change explanations and manage user questions without changing
  source files. Discover explanations for frozen comparison ranges from Compare.
- Read a complete comparison in one continuous Diff tab, with collapsible files,
  bounded context expansion and separate file tabs when needed.
- Reduce repeated document construction during long Diff scrolling. Add a wider
  overview interaction area with change-marker clicks, track positioning, pointer
  dragging and keyboard navigation.
- Keep explanation popovers compact without hover tooltips expanding their scroll
  area. Preserve code anchors across loading, context expansion and view changes.

Implementation validation included TypeScript checks, 537 tests, and isolated
real-host Diff and overview interaction flows. In the fixed multi-file scrolling
sample, frame interval P95 improved from 117.9ms to 18.6ms. Stable-content scrolling
did not rebuild the document or rescan syntax.

Cold scrolling while new files load can still produce isolated long frames;
those remaining costs have not all been attributed. Android/iOS native touch,
gesture interactions and scrolling performance remain device acceptance items.
Change explanations remain author statements rather than requirement approval.

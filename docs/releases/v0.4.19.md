# v0.4.19

- Add Agent-authored change explanations tied to immutable comparison snapshots,
  with authenticated authors, revision checks and idempotent batch writes.
- Show explanations through compact code markers and floating popovers. Details,
  questions and read/confirmation actions are available on demand; explanations
  do not change Diff row heights or scroll overview positions.
- Keep file explanation directories collapsed until requested, and remove the
  horizontal separators between code rows in unified and split Diff views.

Implementation validation included TypeScript checks, 504 tests, and isolated
real-host explanation and Diff UI flows. Android/iOS native appearance, keyboard
and scrolling remain device acceptance items.

Known limitation: the snapshot binary detector can misclassify source text that
contains Git binary/submodule marker strings. Such files currently require
file-level explanations rather than line anchors. Explanations are implementer
statements, not proof of requirement compliance or approval.

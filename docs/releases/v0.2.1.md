# Workspace Workbench v0.2.1

This patch clarifies repository change statistics and reduces background refresh while Paseo is out of focus.

- Repository rows leave the statistics area empty until the selected repository has a current diff result. Valid changes show colored additions and deletions; clean or uncomputed repositories no longer say "Not loaded" or imply zero measured changes.
- The commit graph no longer shows "Not loaded" for uncomputed working-tree line counts.
- Web window blur and page hiding pause automatic version polling and follow-up refreshes. Returning to the foreground checks versions and refreshes changed data. The existing backend observation lease expires normally, and in-flight requests are not cancelled.

Validation: TypeScript typecheck and 183 Node tests passed. An isolated Paseo host and headless browser confirmed clean and changed repository rows, pause/resume on window blur, live file updates, plugin reload, backend recovery, and zero additional Git commands during 16 idle seconds.

Existing Agent MCP processes keep their loaded code until the host reconnects them; plugin reload does not terminate active sessions.

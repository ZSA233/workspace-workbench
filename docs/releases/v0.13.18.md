# v0.13.18

修复当前会话属于本地项目、但多仓库 `sourceRoot` 指向公共父目录时，文件页错误地从公共父目录开始展示的问题。本地项目的主文件目录自动识别，无需修改项目 JSON；多仓库 Git 范围和执行目标保持独立。

- 文件工具栏可单独切换「当前 Workspace／主工作区」，保留各自的展开、筛选和滚动位置。
- 设置菜单和文件位置菜单提供「文件目录设置」，支持自动识别、当前宿主目录及分页浏览主机目录的选择器。
- 修改目录后旧文件实例及文档失效；未完成文件任务阻止改变目标目录，同目录设置保存不会打断任务。

验证范围及平台边界见 [文件工作台验证记录](../workspace-files-verification.md)。

发布检出的版本一致性与 TypeScript 检查通过，完整 Node 回归共 1,080 项，其中 1,079 项通过、1 项按条件跳过、0 失败。实际隔离 Paseo 宿主及 Chromium 文件界面验证通过；没有使用正常实例注册测试项目。

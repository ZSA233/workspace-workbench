# 摘要与设置的第二版交互设计

本目录是设计评审用的 Web UI，不是已经替换插件的 React Native 页面。生产版本、原生标题、归档及项目配置保持原值。

入口采用插件自己的横向导航。窄栏设置首页直接展示当前模型地址、模型 ID、自动整理开关，以及扩展管理、项目存储、审核、执行、仓库、生产、环境、恢复、话题、文件规则和诊断入口。Diff 字号、换行、统一/并排仍留在 Diff 工具栏。

摘要按项目、会话和 Workspace 分清数量及关联。未关联的当前会话提供进入项目资料的操作。选择材料、模型生成、核对预览和应用标题以四步展示。生成任务只有一个取消入口；来源数量、真实模型运行、失败、生成结果及标题是否应用分别显示。生产检查只读进度，不混作模型推理。

`preview-server.mjs` 从 `dist/design/yuva-v2/data.json` 读取本机捕获的私有样例。该目录包含真实业务资料和截图，保持在忽略的 dist 中。页面只通过本机已安装 PASEO CLI 的认证客户端调用现有连接检测、模型测试、测试查询和取消接口；没有写标题、改项目设置、开启自动维护或归档的接口。模型请求只在点击生成或明确运行 `--generate` 时发起，不加载或切换模型。

```sh
node docs/design/organizer-v2/preview-server.mjs
node docs/design/organizer-v2/verify-preview.mjs
# 需要再做一次真实模型试验时才传 --generate
```

设计稿可导出为包含真实试验结果的单个 HTML，在离线状态下继续切换页面、查看材料和核对确认步骤。离线稿不能发起推理。设置修改只保留为页面草稿；确认应用的操作仅展示交互，不调用原生改名。

验证包括 320/360/480/680px 的摘要及所有设置页、模型地址入口、开关、扩展/存储/审核入口、真实模型来源校验、生成前后标题对照、独立确认步骤和离线 HTML。模型来源校验失败不会显示“已生成”，失败记录可在诊断中查看。

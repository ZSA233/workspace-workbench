# 0.13.2

会话页增加“关联工作区”弹窗，支持搜索、多选、取消选择和保存。没有创建者记录的旧工作区可手动关联，取消的自动关联不会在普通刷新后重新加入。

已核对的关联持久保存到当前主机、项目和会话，修复关联依赖活动 Agent 列表、以及旧项目刷新重建列表时清空关联的问题。关联使用工作区实例身份，保留历史与未知字段；不改执行 Agent、创建者、Git 分支或目录。手动修改关联会取消过期分析、清除旧标题预览并暂停标题自动更新，重新确认后恢复。

验证包括真实隔离 PASEO 中的关联弹窗、搜索、取消、保存、进入 Git、重新读取和取消关联，以及归档或缺失 Agent、插件重载、旧项目刷新、实例替换、并发取消和旧预览失效的 Node 回归。正常 YUVA 会话仅做关联读取核对，不按名称猜测或自动绑定工作区。

TypeScript、995 项 Node 回归及 10 项实际隔离宿主界面检查通过；界面中的 Agent 和模型使用协议／HTTP 夹具，覆盖四种窄栏宽度及宿主深浅主题。版本检查和插件打包通过。

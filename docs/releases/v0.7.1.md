# Workspace Workbench 0.7.1

本版减少隐藏页面的后台请求和重复解析，改善远程下载与文件目录较多时的使用体验，保持 Paseo 0.12 兼容。

- 隐藏闲置文件页停止轮询和界面订阅；正在传输、保存或打包的任务继续推进。返回显示原缓存并合并校验，相同目录和 Git 状态不重建树。
- 修复超过 128 个仓库时预热循环；相同源码的并发高亮共享解析，滚动时合并到最新视口，独立取消不打断其他查看者。
- 下载采用有界预读，并将已持久暂存的进度合并到读取请求。512 KiB 分块、两文件、全局最多四个数据请求；最终确认和成功关闭后的完成语义保留。旧后端继续兼容。
- ZIP 准备进度按 250 ms／128 项合并落盘，不影响上传确认和关键任务状态的持久性。
- 目录先返回首批内容，再准备跨页统一排序。索引计入既有缓存预算，超预算使用有界排序窗口；选中、滚动和操作期间不跳动换序。
- 配合 Pocket 0.1.7 支持多个保存目标，选择下一个位置时不阻塞已有写入；旧 Pocket 自动顺序等待。下载仍先选择位置，取消不创建任务。
- 修复从文件查看页返回时偏好恢复可能覆盖目标 Workspace 的时序问题。

20 次交错对照中，8 MiB 下载在模拟 100／200 ms RTT 下中位耗时减少约 69%／70%；650 项 ZIP 的日志写入中位数由 654 次降为 8 次。实际宿主界面没有达到回归阈值的交互退步，隐藏闲置面板的周期文件请求降为零。

[验收记录与平台待验收项](https://github.com/ZSA233/workspace-workbench/blob/v0.7.1/docs/verification/ux-performance-0.7.1.md)包含类型检查、完整回归、实际隔离宿主、4 GiB+ 文件／ZIP64、Pocket 构建及测试结果。Windows 实际客户端和 Pocket 真机尚待验收；Android 模拟器在启动时崩溃，没有将构建或 JVM 测试当作设备通过。

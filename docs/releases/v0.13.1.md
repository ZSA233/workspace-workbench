# 0.13.1

取消钉钉话题和 TAPD 缺陷按格式标签直接禁用附件的判断。上游只提供 `image`、
漏填类型或使用陌生格式时，仍可勾选原件；图片按归档原件的实际响应补齐格式。
浏览器预览失败不再阻断发送，模型图片入口不支持的格式保留原始字节，按文件附件发送。
常见图片类型别名和带参数的类型自动归一，无需逐张人工修正归档记录。

本版通过插件更新交付，不修改或重启 Paseo 宿主，也不修改 Communications Service。
验证覆盖真实归档图片的只读核对、通用 `image` 标签的界面选材与原图发送，
以及钉钉/TAPD 的陌生图片格式按文件交接。模型发送测试使用隔离协议夹具。
TypeScript、988 项 Node 回归、37 项实际隔离 Paseo 界面检查通过；最终改动另通过 71 项受影响测试。

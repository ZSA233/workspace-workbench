# 会话页布局与交互验收

基准：`accepted-list-a.png` 与 `accepted-title-preview.png`。图只决定排布；实际组件、字号、主题色、按钮和弹窗来自原 Git/话题实现。生成图的背景纹理不进入产品。

## 对照检查

| 检查点 | 实际结果 |
| --- | --- |
| 导航 | 原横向导航增加“会话”；“摘要”“设置”与分类导航移除；英文宿主显示 Session |
| 信息结构 | 当前会话标题、预览入口、一个会话开关、关联 Workspace 平铺列表；无卡片堆叠或生成步骤 |
| 列表 | 短需求名、原名称、日期、两行内摘要、生产状态；整行点击打开 Git |
| 选择 | 原选中色及左边线标出手动选择；切换宿主会话不选择另一个工作区 |
| 字号与密度 | 标题/正文 13px、摘要 12px、元数据 11px，沿用原工作台密度 |
| 主题 | 宿主深/浅主题使用原 surface/border/foreground 和语义色，无独立配色系统 |
| 弹窗 | 当前题与建议题分组、一个主要确认按钮；自然高度，依据展开后滚动 |
| 窄栏 | 320/360/480/680px，实际宿主分配区域及内容分别检查，不允许依靠父级裁切掩盖溢出 |

修复了初版实测中的过高空白弹窗和测试分配区域裁切。保留原顶部工作区选择器、审核入口以及底部文件传输条；实际工作区排序、摘要文案和生产状态取决于数据，不硬编码示意图内容。无未经批准的首页指标、卡片、说明段落或菜单层级。

## 使用路径

实际隔离 PASEO 中逐项点击：会话打开自动摘要；工作区行进入 Git；预览取消不写标题；确认后启用，再关闭；原菜单打开模型、存储、运行时、审核、扩展；同项目会话切换；跨项目选择恢复。两种主题与四种宽度均检查。

Browser/IAB 工具不可用，采用仓库 Playwright Chromium 跑实际隔离宿主。协议 Agent 和 HTTP 模型为测试夹具；最终界面回放独立真实 Sushi/YUVA 试验已校验的摘要文案。它是实际插件渲染证据，不等同于在用户正常宿主派发真实 Agent。正常宿主仅按正式发布流程更新。

真实模型试验另用当前 YUVA 的实际只读提交、说明、差异与公开会话增量，在隔离配置与存储中运行。模型输入/输出及来源校验有独立记录，真实业务标题写入次数为零。冷启动样例一次请求处理三个有提交的工作区和会话标题约17秒，缓存预览约6秒且0次模型调用；此为当前样例测量，不作为其他项目的固定时延承诺。

可复现：`npm --prefix paseo-plugin run test:organizer-ui`。设置 `WORKBENCH_SESSION_MODEL_REPLAY` 为本机已验证的会话 snapshot.json 时，仅替换模型夹具文案，报告明确标记 real YUVA output replay。

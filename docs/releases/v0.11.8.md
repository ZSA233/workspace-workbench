# 0.11.8

修复钉钉和 TAPD 发送后的图片回显位置。原图显示在已接受的正文之后，明确标注图片、视频和附件数量；三张不同的 TAPD 原图不会只留下附件名称。历史记录可补正显示位置，保留原时间线身份，重试显示不会重复派发任务。预览读取失败时显示文件名和重试入口。

图片、视频和普通附件共用聊天查看组件。PDF 等已发送附件显示名称、大小，并共用 Pocket 原生保存、Access 保存交接和浏览器下载；原件分块读取时校验版本和内容。

范围更正：本版曾包含用于隔离验证的可选宿主附件历史适配器。因绑定原生源码版本、不符合正常升级的维护要求，该方案已停止正式启用，日常宿主均未安装启动选项；v0.11.9 将实验移出发布包。Pocket/Access Pocket 的跨端历史问题尚未正式修复，不能将本次插件更新或实验结果视为其已上线。见[维护边界](../design/cross-client-attachment-history.md)。

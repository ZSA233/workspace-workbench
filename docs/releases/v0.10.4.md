# 0.10.4

话题材料可在发送前逐条编辑、补充和还原，原始归档与版本保存在私有快照中。多人对话保留发言者与日期时间，并跨话题按原始时间排列；单人默认使用简洁正文。图片按所属消息顺序发送，继续通过宿主原图输入交付。

参与者化名使用来源身份、选中发言者及可确认的提及关系建立对应，同一批材料补选上下文时不重排已有编号。无法确认的称呼保留并列出供人工编辑；代码、邮箱与链接保持原样，不整段删除 @ 内容。

发送确认的三点菜单提供排版、化名对应、发送预览和可编辑的说明模板。常用预设按主机与项目保存，本次原文编辑与补充说明留在当前选材中。发送前固定本次编辑和模板结果，未知回执仍只查询，不自动重发。

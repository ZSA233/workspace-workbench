# 0.11.10

修复钉钉回复引用图片时出现永久“等待原件”的附件框。连接器根据同版本原文的资源归属，
区分当前消息上传的附件和引用消息的附件；引用内容显示为轻量提示，可通过上下文查看原图。
当前消息真正上传的图片继续显示，引用附件不再重复计数、默认选入材料或触发无效轮询。

真正待归档的附件仍每 10 秒自动检查就绪状态，就绪后显示原图并停止轮询。
刷新保留历史正文、消息版本、附件身份和已经选择的材料，不自动增加发送内容。
无需修改或重启 Paseo 宿主，也无需修改 Communications Service。

验证：TypeScript 和 938 项 Node 测试通过。真实隔离 Paseo 通过 37 项界面检查，
覆盖桌面和窄屏引用提示、上下文原图、真实待归档图片自动就绪和选材保持。
归档和模型使用协议夹具，没有向真实模型派发测试任务；另以只读方式核对了实际归档中
本条上传图片与引用资源的归属，未改变归档数据或原图。

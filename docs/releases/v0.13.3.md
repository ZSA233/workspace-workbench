# 0.13.3

“关联工作区”默认带出顶部当前选中的工作区和当前 PASEO 会话，一次确认即可添加关联。已有关联保留，当前工作区已关联时直接显示状态；“选择其他工作区”进入原有搜索、多选列表。

确认对象按打开时的项目、会话和工作区实例核对，主工作区或失效的选择直接进入列表。弹窗显示从宿主读取的当前会话标题。取消不保存；原有执行绑定、标题授权、模型设置和关联存储沿用原行为。

TypeScript、995 项 Node 回归和 12 项实际隔离 PASEO 界面检查通过。界面验证使用协议 Agent／HTTP 模型夹具，覆盖默认确认、取消、已关联状态、改选、多关联保留和既有导航，并检查四种窄栏宽度及深浅主题。

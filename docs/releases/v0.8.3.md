# 0.8.3

文件面板的错误提示移到底部已有的状态栏，长路径报错不再插入工具栏与文件树之间。

- 状态栏高度固定，保留文件数量、选择状态与拖放提示；异常只显示紧凑的「文件提示」入口。
- 主动点击后查看完整错误和路径，可刷新目录或忽略。后台检查不会自动打开详情或抢走输入焦点。
- 同一提示忽略后不随轮询重复出现；其他错误仍可显示。新建、重命名等操作失败时，仍在当前操作窗口内提示。
- 文件提示支持键盘打开；详情滚动区域有高度上限，适配窄窗口。

验证：TypeScript 检查、815 项 Node 测试及插件打包检查通过。真实隔离 Paseo 宿主的文件提示专项通过，使用真实目录删除触发 ENOENT，覆盖宽／窄窗口、文件行与状态栏位置、输入焦点、键盘打开详情、刷新恢复及忽略后持续轮询。

提示专项可通过 `WORKBENCH_FILES_NOTICES_ONLY=1 node --experimental-strip-types paseo-plugin/scripts/verify-files-ui.mjs` 重现。完整文件脚本的浏览器下载场景此前出现超时，未计入本次已通过的界面验证。另修正活动时间测试对 Git 等价 UTC 时间格式的比较，不改变运行时行为。

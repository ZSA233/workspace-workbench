# Workspace Workbench 0.7.8

配合 Pocket 0.1.11，在 Paseo Web 0.12.0 右侧文件／变更栏增加 Workbench Tab。保留当前会话，首次选中才加载工作台；按主机与 Workspace 记忆页签，打开文件或 Diff 时收起侧栏，“返回文件”重新展开。

新增可随 Paseo 插件打包的 Pocket SDK v1。其他已安装插件也能引用自己的面板接入右侧栏，复用原 RPC、主题和查询缓存，支持标题更新及自动清理。无需新增扩展安装流程。普通浏览器、桌面和旧 Pocket 保留原入口。

通过插件 typecheck、749 项 Node 回归、Hermes、隔离实际 Paseo 的双插件验证及 Pocket 模拟器验证。每版 20 个交错性能样本未发现超过约定阈值的交互退步；未打开和隐藏闲置的面板不产生业务查询。

# 0.12.0

新增 Workbench“摘要”和“设置”Tab。设置按分类下拉、单列表单和折叠组重新编排，保留既有存储与服务；切换分类保留草稿，切换编辑项目/范围先处理未保存内容。主机模型连接不依赖选中 Workspace 或项目后端就绪。

支持本地 Sushi Chat Completions、多连接、主机私有认证、上下文/输出/超时和有界并发配置。摘要整理目标、自身提交、必要差异、改动说明及公开会话增量；事项保留人工编辑、来源和长消息断点。模型测试后台运行，展示实际输入输出，可取消，不写标题。

历史条目先生成预览，显式应用后才接管标题。未来明确关联的条目可按范围自动维护。标题正文稳定，状态默认用 `✓ / ◐ / ○ / ? / ·`；外部改名自动暂停，可仅维护符号、排除或受保护地恢复原标题。生产覆盖核验冻结基线及当前生产内容，支持等价 squash/cherry-pick 并保守处理回滚和缺失证据。归档仍由用户手动操作。

TypeScript 与 961 项 Node 回归通过，发布版本与归档包校验通过。

验证区分三类证据：Node/Git 回归；实际隔离 Paseo 加协议会话和 HTTP 模型夹具的标题与窄栏 UI 验证；真实 Sushi 对三组已有 Workspace 的只读生成。真实模型试验显示了输入截断，并验证超时和不完整输出被拒绝；没有改动这些业务会话标题。原生列表只使用标题字符，额外原生徽标尚未开放。

使用方式与数据位置见 [整理说明](../../paseo-plugin/ORGANIZER.md)。

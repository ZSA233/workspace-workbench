# Paseo Pocket 0.1.6

版本：0.1.6 / versionCode 7；包名：`dev.paseo.pocket`。沿用已有持久签名，可覆盖升级 0.1.5。

本版加入 Workspace 文件下载的 Android 系统保存桥，配合 Workbench 插件 0.6.0：

- 下载先选择名称和系统保存位置，确认后才创建传输任务；取消选择不产生任务或写入。
- 下载内容按最多 512 KiB 分块写入所选文档，验证确认偏移，关闭输出成功后才确认完成。
- 上传沿用系统文件选择器，支持插件中的选文件上传。网页和 APK 继续独立升级；只有更新 APK 才能增加原生保存能力。
- 保存桥仅允许可信的本地主页面调用，不接受任意远端 URL 或本机文件路径，不向其他来源或子框架开放。
- 页面重建中断最终保存时，需要重新选择保存位置；本版未加入后台常驻文件传输服务。

应用内打开「应用升级」即可检查本版。网页更新按钮用于网页资源，不会安装原生文件保存桥。插件请另行更新到 0.6.0。

发布包含 APK、release.json 和 SHA256SUMS；APK 的版本、包名、39 个锁定网页资源和文件保存桥均检查后发布，签名身份保持不变。

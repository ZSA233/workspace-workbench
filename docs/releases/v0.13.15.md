# 0.13.15

工作区选择改为按主机、项目和 PASEO 会话分别记忆。切回会话时恢复它上次选中的工作区，刷新页面后也能恢复，不再读取其他会话共用的项目选择。

- 首次没有独立记录时按当前目录识别；识别失败或旧选择已移除时优先回到项目主工作区。
- 继续读取旧版明确按会话保存的选择。旧项目级共享记录保留，但不猜测属于哪个会话，也不复制到所有会话。
- 切换作用范围时不暴露上一会话的选中值；较晚完成的旧操作只保存到原会话，不覆盖当前会话。
- 顶部工作区选择与会话关联、标题维护分开；手动选其他工作区不改变关联范围。现有 Tab 和布局偏好沿用原逻辑。

旧版没有记录所属会话的选择无法完整还原；没有独立记录的会话需重新选择一次，之后分别保存。不改变 Workspace ID、分支、执行权限或归档状态。

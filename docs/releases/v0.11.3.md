# 0.11.3

钉钉话题与 TAPD 缺陷共用列表行、详情容器、材料行及附件网格。两个页签的展开内容使用同样的缩进、竖线、分隔和勾选交互，各来源保留消息上下文、描述及评论等操作。

图片、视频预览、选材和发送确认使用共同组件。视频卡片显示文件名、大小和可用画面，画面解码失败时保留明确的文件卡片。视频单件支持到 24 MiB，材料合计上限为 24 MiB。可用的时间点画面在空间允许时一起交接，原视频通过宿主文件附件发送。

画面提取有总时间限制，缺少工具、无法解码或提取超时会回退到原视频文件。两边选中同一视频时按原件内容去重，并按实际发送的唯一文件计算大小。较大视频通过画面和文件信息展示，支持直接选中并发送原件。

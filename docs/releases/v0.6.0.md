# Workspace Workbench 0.6.0

Workspace 现在可以在同一工作台中管理远程文件。「Git」保持默认页，「文件」紧邻其右侧。

- 紧凑文件树支持文件和目录上传、多选 ZIP 下载、跨 Workspace 复制和剪切、树内移动、重命名及确认后永久删除。
- 点击下载先选择保存位置，确认后才创建任务。取消选择不产生传输记录；完成后自动保存，不需要再去队列点击保存。
- 大量选中路径按请求预算分批确认，使用一个稳定任务 ID 生成同一个 ZIP，一次选择保存位置即可。
- 传输任务保留确认进度、校验信息和恢复身份；ZIP64 与分块 I/O 避免整文件进入内存。浏览器缺少保存接口时由浏览器原生下载接管，插件不声称已保存完成。
- 文件显示 Git 颜色和字母，目录显示汇总圆点，忽略项灰显。主目录和未登记的可见仓库也读取真实 Git 规则，不扩大任务或审查范围；已跟踪文件不会因忽略规则灰显。
- 上传及删除完成后更新受影响目录并保留树的位置，旧响应不能恢复已删除条目。拖回原位、放到自身和取消拖动不创建任务。
- 操作菜单列出已选名称、完整相对路径与数量，上传、新建、粘贴的目录单独标明。
- 有界观察缓存清理 Workspace 归属，传输日志单独保存。空间移除不会遗留迟到的派生缓存。

Pocket 用户请同时升级到 0.1.6，获得 Android 原生系统保存选择器。页面重建导致保存权限丢失、或最终保存失败时，恢复任务仍可能需要重新选择保存位置。

类型检查、Node 回归、隔离实际 Paseo 宿主的文件交互、主题和触控验证均用于发布验证。Windows 实际客户端与 Pocket 物理设备结果需单独记录，不能以 Chromium 或 Android 模拟器代替。

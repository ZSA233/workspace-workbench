# Workspace Workbench 0.7.3

普通文本的比较说明现在必须定位到具体代码行，避免说明只挂在整个文件上。

- 写入时要求旧侧／新侧及完整行范围，并验证范围属于捕获的补丁；缺少行号不会降级成文件级说明。
- 工具接口和“复制本次比较的说明请求”同步提示选取相关行段。合法说明使用已有的行旁气泡、范围高亮和跳转。
- 二进制、Gitlink、截断补丁和纯重命名等没有可定位行的变化保留文件级说明。旧记录、重试和历史继续可读；旧的文件级说明需重新核对位置，不会猜测行号迁移。

类型检查、完整本地 Node 回归及隔离实际 Paseo 宿主的认证 MCP／行定位检查通过。[验证记录](https://github.com/ZSA233/workspace-workbench/blob/v0.7.3/docs/verification/line-explanations.md)。

手机现有入口是左侧菜单 → Workspace Workbench。Paseo 0.12 的紧凑右侧栏需要宿主扩展支持才能增加插件 Tab；[实际验证与来源](https://github.com/ZSA233/workspace-workbench/blob/v0.7.3/docs/verification/mobile-entry-0.12.md)。

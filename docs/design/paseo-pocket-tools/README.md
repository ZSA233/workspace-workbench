# Paseo Pocket 悬浮工具与 Logo 草图

状态：设计讨论稿，2026-10-21。只增加设计文件，未替换 Android App 的图标或界面。
会话、主机名、版本状态均为示例；所有交互仅改变草图，不调用主机或执行任务。

## 悬浮入口与菜单

`paseo-pocket-tools.html` 提供三个可切换、可点击的草图：

| 方案 | 常驻入口 | 点击后 | 取舍 |
| --- | --- | --- | --- |
| 贴边半屏面板 | 窄侧柄，符号代替 PP | 底部四格工具面板 | 常驻遮挡最少，操作目标宽裕 |
| 就近工具卡 | 圆角方钮 | 按钮附近展开紧凑工具卡 | 保留上下文，面板位置需避开输入法 |
| 清晰列表面板 | 符号与“工具”胶囊 | 分组列表面板 | 发现性强，常驻占用略多 |

保留外观、网页版本、更新来源、缓存与诊断四项能力。用图标、主次文字和分组替代
四个等重的描边按钮，不增加地址栏、固定导航或第二套主机管理。
关闭菜单保留示例输入；可拖动入口改变停靠侧和高度。设置只在草图内生效。

后续实现仍应保留至少 48dp 触控范围，处理安全区、键盘与返回顺序，不刷新 WebView。
侧柄不能把可点击区域挤进系统返回手势区。初稿不加入持续动画、模糊或后台轮询。

## Logo

三个独立、可编辑的单色 SVG：

- `route.svg`：路径与端点，表达 Paseo 的行进和连接。
- `pocket.svg`：口袋与终端光标，表达随身工作区。
- `portal.svg`：相连的窗口，表达从手机进入远端工作区。

`paseo-pocket-logos.html` 展示轮廓、启动图标容器与小尺寸表现。
草图先讨论结构；颜色、细节与最终标志尚未定稿。没有沿用官方商标或个人域名。
按本次要求手绘品牌 SVG；普通界面动作图标使用 Lucide。

初步倾向：**贴边半屏面板 + 路径标志**。最终选择之后再细化 Android VectorDrawable、
自适应启动图标、深浅主题与不同密度资源；当前 APK 保持不变。

## 草图验证

已在 Chromium 中检查 320px、736px 两种宽度及明亮、深色两种外观，三套方案均无
横向溢出或脚本异常。验证了设置切换、更新来源输入、关闭重开菜单、拖动吸边及
切换方案后保留示例草稿；三个 Logo 的偏好选择正常。独立 SVG 已通过 XML 解析。
这些结果属于浏览器草图验证，不代表 Android 实机上的最终实现验收。

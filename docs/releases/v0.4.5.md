# Workspace Workbench v0.4.5

This patch completes the shared MCP gateway recovery changes and stabilizes the release checks for saturated diagnostics and queued HTTP calls.

- Preserve each Paseo home’s gateway port and key across plugin reloads and gateway crashes; wait for a verified prior owner and report unverified port conflicts without changing the address.
- Check Paseo and plugin RPC readiness before injecting the gateway, expose `workbench_connection_status`, and restart a crashed gateway with bounded backoff.
- Count HTTP queue time toward request deadlines and refuse to dispatch requests that expired while waiting for a slot.
- Return stable request identities for uncertain create and submit results, and ensure the project backend is ready before dispatching writes.
- Wait for pending diagnostic writes to finish during shutdown so failure events are preserved.
- Make the HTTP queue regression test use independent client connections, ensuring it exercises the server queue instead of client-side connection pooling.

Validation: TypeScript typecheck, the full 241-test Node suite, and isolated actual-Paseo verification passed. The live check created a Workspace through MCP before and after plugin reload without changing the gateway URL or key.
